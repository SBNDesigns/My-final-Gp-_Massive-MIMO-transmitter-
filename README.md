# My-final-Gp-_Massive-MIMO-transmitter-
This my final graduation project in digital IC design track. 
This project presents the design, implementation, and full hardware realization 
of a Massive MIMO (Multiple-Input Multiple-Output) digital beamforming 
transmitter operating at millimeter-wave (mmWave) frequencies for 5G wireless 
communication systems. The transmitter employs a fully digital beamforming 
architecture at the baseband level, enabling precise, independent phase and 
amplitude control over each antenna element to achieve directional beam 
steering, suppress multi-user interference, and maximize spectral efficiency.
